🖼️ Image Resolution — Interactive Lab

Understand what resolution really means: how many pixels are used to represent an image

1️⃣ What Is Image Resolution?

A digital image is made from a grid of tiny pixels.

The resolution tells us how many pixels are used to represent the image usually expressed as:

Width × Height

For example:

1920 × 1080

Width = 1920 pixels
Height = 1080 pixels

Total pixels = 1920 × 1080 = 2,073,600 pixels

4️⃣ What Does "Fewer Pixels" Actually Mean?

Suppose we start with:

1920 × 1080 = 2,073,600 pixels

Now reduce it to:

100 × 100 = 10,000 pixels

The image is now represented using only 10,000 pixels instead of 2,073,600 pixels

And at 20 × 20?

20 × 20 = 400 pixels

Only 400 pixels are available to describe the entire image That means much less spatial detail can be represented

5️⃣ Think About It

What happens when we reduce the number of pixels?

When we reduce the number of pixels the image contains less spatial information Fine details can disappear because there are fewer pixels available to represent them So:

More pixels → more detail can be represented
Fewer pixels → less detail can be represented

6️⃣ Connect It to OpenCV

In OpenCV we can change the resolution of an image using:

resized = cv2.resize( img, (100, 100) )

Here:

  • The original image is stored in img
  • The new size is (100, 100)
  • OpenCV creates a new image represented by 100 × 100 pixels
Important:

The second argument is:

(width, height)

So:
(100, 100) means:
100 pixels wide × 100 pixels high.

7️⃣ Final Mental Model

HIGH RESOLUTION 1920 × 1080 = 2,073,600 pixels --> More pixels available to represent spatial details

LOWER RESOLUTION 100 × 100 = 10,000 pixels --> Fewer pixels available to represent spatial details

VERY LOW RESOLUTION 20 × 20 = 400 pixels --> Very limited spatial detail
