Look carefully at what changed:

At the end: Gray → one intensity value

Approximate conversion:
Gray ≈ 0.299R + 0.587G + 0.114B
🤔 Ask the students:

If a pixel starts as: RGB = [220, 80, 40] What happens to the separate Red, Green and Blue information when we convert it to grayscale?
The three color channels are no longer stored as three independent color values The grayscale pixel is represented by one intensity value describing how bright or dark the pixel is So we move conceptually from:

[R, G, B] ↓ [Gray]

3️⃣ Color Image → Red / Green / Blue Channels

A color image can be separated into three 2D channels Each channel is basically a matrix containing values from 0 to 255

Original: Red + Green + Blue work together to produce the final color.

4️⃣ RGB vs BGR

Here the important point is: Same three values OpenCV commonly stores a 3-channel image in BGR order

RGB

OpenCV BGR

pixel = img[y, x]
B, G, R = img[y, x]
